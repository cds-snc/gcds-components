# Navigation<br/>`<gcds-nav>`

_Replaces: `<gcds-top-nav>` and `<gcds-side-nav>`._

A navigation for a site or section. Use `variant="top"` for a horizontal navigation in the header
and `variant="side"` for a vertical navigation next to the page content.
On small screens, every navigation on the page is combined into one menu button.

## Migrating from gcds-top-nav and gcds-side-nav

Rename the tag and keep the children:

- `<gcds-top-nav>` → `<gcds-nav variant="top">`
- `<gcds-side-nav>` → `<gcds-nav variant="side">`
- `menu-label` on `<gcds-nav-group>` is no longer needed, `open-trigger` is the group label.

## Single page apps

Connect your router once and every navigation uses client side routing and highlights the current page:

- React: `<GcdsRouterProvider navigate={useNavigate()} currentHref={useLocation().pathname}>`
- Angular: `provideGcdsRouting()` in your application providers
- Vue: `app.use(GcdsComponents, { router })`
- Other frameworks: `setNavigationHandler()` and `setCurrentHref()` from `@gcds-core/components`
